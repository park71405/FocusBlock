# 타임 박싱 도입 To-Do 웹사이트 - FocusBolck

#### 목적

- 뇌과학적 원리인 ‘타임박싱’을 디지털 환경에 이식하여, 사용자가 의지력을 소모하지 않고도 바로 행동에 몰입할 수 있는 구조적 환경을 제공하는 것

#### 프로젝트 기간

- 5월 1일 ~ 27일

#### 기술 스택

- Front-End : React
- Back-End : Spring Boot, JPA
- Data
- Infra-Structure

#### 구현제약사항

- if statement는 else if는 사용하지 않는다. (사용시, 이유 명시)
- Validation은 Front-End & Back-End 모두 구현한다.
- 다수의 사용자가 이용할 것을 감안하여 로그인 기능을 제공한다.
- 코드 작성 시, 주석 작성 금지. 쿼리작성 및 a에서 언급한 상황 외에는 주석을 작성하지 않는다.
- 소스 형상관리는 편한 기술을 이용하나, Main Branch에서 직접 개발하지 않는다.
    - main : 최종 배포용
    - dev : 통합 브랜치, 기능 구현 기준점
    - feature/{기능} : 신 기능 구현
- 배포 및 도메인 필수
